# [/] BUFF_MC-VLogger
Simple logger bot for When Yah Season 2 Minecraft Server

## Usage
> - display in-game chat to discord server
> - run/trigger minecraft command from discord server
> - show minecraft server status
> - show online players

## Commands
> - /list >> list all online player
> - /trigger [command] >> run/trigger a minecraft command
> - /status >> show current server status
